I'm Luan Erasmus. I like building things, automating the boring bits, and figuring out why something broke. Occasionally, I'm the reason it broke.

Automation is a big part of what I enjoy about development. If I'm doing the same task by hand over and over, I'll usually start wondering whether I can write something to do it for me. There's something satisfying about turning a repetitive process into a tool that does the job consistently.

I spend a lot of time working with GitHub, CI/CD, and GitHub Actions. I'm interested in how they fit together and how useful tools and workflows can make it easier to get code from an idea into production.

Away from the keyboard, I enjoy playing darts and golf. Both give me a chance to switch off and come back to a problem with a clearer head.

This blog is where I'll write about things I'm learning, projects I'm building, and problems I've had to work through. Expect plenty of GitHub and automation, along with a few lessons learned the hard way.

Welcome!
